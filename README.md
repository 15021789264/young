# Young - Base L2 Project

This project is configured for development on the **Base** network (Ethereum Layer 2).

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Configure environment variables:
Copy `.env.example` to `.env` and add your private key.

3. Compile contracts:
```bash
npx hardhat compile
```

4. Deploy to Base Sepolia:
```bash
npm run deploy:sepolia
```

## Network Details

- **Currency:** ETH
